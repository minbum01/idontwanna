## 0. 빠른 시작 (집에서)

```
cd "합격선/_통합산출"
git pull
python build_book.py          # 파트 HTML들 → 포켓북_전체.html 생성(통합본)
start 포켓북_전체.html         # 브라우저 두쪽보기로 확인
```

- **통합본 = `포켓북_전체.html`** (build_book.py가 자동 생성, 직접 수정 금지)
- 각 PART는 개별 파일을 수정 → `build_book.py` 다시 실행
- **folio(쪽번호)는 build_book.py가 물리 페이지 순서대로 자동 부여** (각 파일의 `<span class="pg serif">0</span>`은 자리표시자)

### 넘침(overflow) 검수 — Edge 헤드리스로 전수 측정
poppler 없어 PDF 뷰는 안 되지만, Edge로 모든 페이지의 세로 넘침을 JS로 잴 수 있다:
```
# 포켓북_전체.html 사본에 <style>.page{overflow:visible!important}</style> + 측정 스크립트 주입 후
msedge --headless=new --disable-gpu --no-sandbox --user-data-dir=<temp> \
  --virtual-time-budget=8000 --dump-dom _a.html | grep 'data-r'
# data-r="OVF[0]=" 이면 넘침 0
```
페이지 스크린샷도 Edge `--screenshot`(force-device-scale-factor=2)로 가능 → PNG는 Read로 볼 수 있음.

## 2. 핵심 규칙 / 결정사항 (반드시 준수)

1. **공채(공개경쟁) 기준** — 경채 제외. 지방직 9·7급/교행 모두.
2. **경쟁률 대신 실제 인원(선발·접수)** — "경쟁률은 의미 없다, 몇 명 뽑고 몇 명 몰리는지". 시도별 표는 선발/접수 인원으로.
3. **모든 페이지에 2026 포함** — 합격선이 없으면(필기 전) 최소 선발/접수(접수현황·선발예정)라도. 2026-왼쪽 배치 + 연파랑(.yhi) 별색.
4. **합격선 색인**: 연도마다 **선발과 합격선을 따로 칸**으로 (`’26선 | ’25선 ’25컷 | ’24선 ’24컷 | ’23선 ’23컷`). 합격선 칸은 연파랑 음영. **각종 시·군(임용기관) 전수**가 다 들어가야 함.
5. **교행 합격선 = 총점÷5(과목평균 100점 환산)** — 교행 9급 전 시·도 만점 500(5과목) 확인됨(총점 최대 425~475). 시·도 비교 가능.
6. **지방직 합격선은 시·도×직렬 매트릭스** + 시·군 전수 색인 두 축.
7. 합격선 기준 = **과목평균 100점**(국가직·지방9급·지방7급). 교행만 총점→÷5.
8. 디자인: 네이비/블루 2도, Pretendard(OFL), 인쇄 A5 페이지네이션. 원본 데이터 수정 금지. 인쇄물이라 **정확도 최우선**.

## 5. 중단/대기 작업 (집에서 이어서 — 우선순위 순)

1. **[대기] 지방 7급 직류별 2026 선발예정** — 5-1엔 총계(394)만. 국가직 7급처럼 직류별 ’26 선발예정 컬럼/표 추가 여지. (※ 지방7급 직류별 선발 공식분해 자료 확인 필요)
2. **[대기] 교행·지방7급도 시·군(기관) 전수 색인** — 지방9급처럼. "지난번에 결정"으로 **일단 보류**. 교행은 col5 기관 있음(÷5 환산 적용), 7급은 표본 작음.
3. **[대기] 지방9급 색인 밀도/분량 조정** — 현재 ~40p(전체 ~104p). 너무 많으면 ① 2025 단년만 남기기 ② 소수 직렬 제외 ③ 단당 행수↑(현재 N=44, 페이지에 여백 남음 → 더 빽빽이) 로 절반 가능.
4. **[자료대기] 근로감독·산업안전 2026** — 현재 0-2에서 "—"(2025 신설, 2026 자료 없음). 자료 생기면 추가.
5. **[검증대기] 지방 교육행정 공식 출처** — 현재 v3 집계값(교육행정 직렬). 행안부 PDF엔 교행 없음(교육청 별도). 교육청 발표자료 구하면 교체.
6. **[보강] 지방 7급 합격선** — v3 표본이 서울·경기 위주로 작음. 직렬별 중앙값만 수록(5-3). 시도별/연도별 보강 필요.
7. **[옵션] 지방9급 매트릭스 직렬 확대** — 현재 행정계5(행정·복지·세무·전산·사서)/기술계7(시설·공업·농업·녹지·환경·보건·방재). 더 넣을지.
8. **[검토] 다직류 색인 라벨** — 시설/공업/전산은 "기관·직류"(예: 수원시·토목)로 표기, '일반' 접두 약어화·max-width 16mm. 잘림 더 줄일지.

## 6. 색인/매트릭스 재생성 메모 (스크립트는 1회용으로 삭제됨 — 로직만 기록)

- 시·군 색인: v3 RAW에서 `직급=9급 & 시험종류=공무원 & 시도∈17 & 시험구분~공개 & 대상=일반`, key=(시도, col5기관, 직류). 직렬별로 묶어 2단(좌N+우N, N≈44) 표. 행: `시도 | 기관 | ’26선 | ’25선 ’25컷 | ’24선 ’24컷 | ’23선 ’23컷`. 클래스 `.sgun.sg3`(컷=`.ct` 굵게, 헤더 `th.ct` 연파랑).
- 매트릭스: 시도(17행) × 직렬(열) 2025 합격선 중앙값(과목평균, 일반, 30점이상). 클래스 `.mtx`.
- 막대(lbars): 2026 선발 로그 척도, 우측 합격선. `x=−58+33·log10(v)`류 스케일.
- 교행 ÷5: 합격선기준='총점'이면 ÷5, '과목평균'이면 그대로.
